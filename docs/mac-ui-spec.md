# 桌面版 JKMUSIC UI 规格（iOS 适配基准）

> 依据：`references/mac-ui/screenshots/mac-*.png`（桌面版真机截图，2 倍图，2228×1436 → CSS 1114×718）
> 与 `references/mac-ui/` 还原源码。**所有视觉以其截图为准，禁止自创。**
> 手机版原则：结构照搬，布局从"左右分栏"塌陷为"单列 + 顶部/横向选择器"。

## 0. 设计令牌

| 令牌 | 值 | 来源 |
|---|---|---|
| `color.primary` | `#E240F7` | 截图采样（导航选中、进度条、按钮） |
| `color.bg` | `#FFFFFF` | 页面底色 |
| `color.text` | `#424242` | 大标题 |
| `color.textStrong` | `#000000` | 列表主文案 |
| `color.textMuted` | `#9B9B9B` | 歌手/专辑/次要信息 |
| `color.fillSubtle` | `#F6F6F6` | 胶囊未选中、卡片底 |
| `color.fillMuted` | `#F3F3F3` | 输入框、标签底 |
| `color.divider` | `#EEEEEE` | 表格分隔线 |
| 圆角 | 胶囊 999 / 卡片 12 / 播放条 14 / 输入框 999 | 截图目测 |
| 字号（CSS px） | 大标题 30 / 页面标题 15 / 卡片标题 15 / 正文 13 / 次要 12 / 角标 10 | 2 倍图折算 |
| 间距 | 页面左右 24 / 区块间 20 / 行内 10 | 截图目测 |

已适配深色模式时，等价替换为：bg `#000000`、text `#F5F5F5`、muted `#8C8C8C`、divider `#1F1F1F`。

## 1. 布局映射（桌面 → 手机）

| 桌面 | 手机 | 说明 |
|---|---|---|
| 左侧栏 Aside（6 项导航） | 底部 TabBar（6 项） | 图标在上、文字在下，选中 `primary` |
| 顶部居中搜索胶囊 | 顶部搜索胶囊（全宽减 24） | 右侧放大镜，左侧清除 |
| 主内容 view | 页面内容 | 双栏页塌陷为单列 |
| 播放条 player | 悬浮迷你播放条（TabBar 之上） | 三段式 |
| 播放详情页 play-detail | 全屏播放页（现有 `/player`） | 保留 |

## 2. 六个页签（顺序与文案必须一致）

| # | 文案 | 图标语义 | 路由 |
|---|---|---|---|
| 1 | 搜索 | magnifier | `jkmusic://search` |
| 2 | 歌单 | music-list / album | `jkmusic://songlist` |
| 3 | 排行榜 | bar-chart | `jkmusic://leaderboard` |
| 4 | 我的列表 | heart | `jkmusic://favorites` |
| 5 | 下载 | download | `jkmusic://downloads` |
| 6 | 设置 | settings / gear | `jkmusic://settings` |

注意：第一项是「搜索」不是「音乐」；第三项是「排行榜」不是「榜单」。

## 3. 各页结构（照截图）

### 3.1 搜索
- 顶部：搜索胶囊（placeholder「Search for something…」桌面为英文，手机版用中文「搜索歌曲、歌手」）
- 大标题「搜索」
- 源筛选行：酷我音乐 / 酷狗音乐 / 企鹅音乐 / 网易音乐 / 咪咕音乐 / 聚合搜索（胶囊，选中为 primary 描边+文字）
- 右侧视图切换：歌曲 / 歌单
- 内容卡（`fillSubtle`，圆角 12，内边距 20）：
  - 分组标题「热门搜索」+ 多行标签（无边框文字）
  - 分组标题「历史搜索」+ 清空图标 + 多行标签
- 搜索结果：复用「五列歌曲行」组件

### 3.2 歌单
- 大标题「歌单」
- 筛选行：左侧排序胶囊「默认 ▾ / 最新 / 最热」；右侧「打开歌单」+「<源> ▾」下拉
  - 手机版：排序胶囊一行；源选择改为「打开歌单」右侧的胶囊行（横向滚动）
- 内容：**横向卡片**，每行 **3 个**（手机版每行 1 个或 2 个，卡片本身保持"左图右文"）
  - 卡片结构：左侧方形封面（桌面 1:1，约 84×84 CSS）→ 右侧：标题（最多 2 行）+ 作者（muted）+ 底行「🎵 曲目数 · 🎧 播放量」
  - 播放量格式：`1.3万` / `90万` / `1.5万`
- 手机版每行 1 个卡片（左图右文），卡片间距 12

### 3.3 排行榜（双栏 → 单列）
- 桌面：左栏「<源> ▾」+ 榜单列表；右栏歌曲表
- 手机：顶部源胶囊行 → 横向滚动的榜单胶囊（飙升榜/新歌榜/热歌榜/抖音热歌榜/铃声榜/热评榜/ACG新歌榜/台湾KKBOX榜/冬日暖心榜…）→ 下方五列歌曲行
- 榜单行右侧带 `>`（桌面为左栏条目，手机改为胶囊或列表行二选一，二选一后保持与歌单页一致的交互）

### 3.4 我的列表（双栏 → 单列）
- 桌面：左栏歌单列表（青回/红尘情歌/知了…），右栏五列歌曲行
- 手机：顶部为大标题「我的列表」+ 右上两个图标（排序、刷新）；下方为**歌单列表行**（左小封面/心形 + 名称 + `>`），点进去是该歌单的五列歌曲行
- 桌面「试听列表 / 我的收藏」两个默认项等价保留

### 3.5 下载
- 顶部 Tab 胶囊行：所有任务 / 正在下载 / 已暂停 / 出错 / 下载完成（选中 primary）
- 表格列：`# | 歌曲名 | 进度 | 状态 | 品质 | 操作`
  - 手机版：行内改为「歌曲名 + 进度条/百分比 + 状态 + 品质 + 右侧操作图标（试听/定位/删除）」
- 空态：无任务时列表区留白，不显示假数据

### 3.6 设置（双栏 → 单列）
- 桌面：左轨 14 项 + 右内容
- 手机：设置首页为分组列表（每项一行 + `>`），进入后是该分区的表单
- 14 个分区（顺序照桌面）：
  1. 基本设置 2. 播放设置 3. 播放详情页设置 4. 桌面歌词设置 5. 搜索设置
  6. 列表设置 7. 下载设置 8. 快捷键设置 9. 数据同步 10. 开放 API
  11. 网络设置 12. 强迫症设置 13. 备份与恢复 14. 其他
- 手机版「桌面歌词设置」「快捷键设置」保留入口并标注「仅桌面版支持，配置会被保存」

## 4. 五列歌曲行（核心复用组件）

| 列 | 桌面宽度占比 | 手机版 |
|---|---|---|
| # | 40px | 显示序号，宽 28 |
| 歌曲名 | 弹性 | 弹性，1 行省略；名称后可有 `SQ`/`tx` 之类角标 |
| 艺术家 | 约 22% | 右对齐或次行（窄屏） |
| 专辑名 | 约 22% | 窄屏隐藏 |
| 时长 | 60px | 右对齐 |

- 行高：桌面 52px；手机 56px（触控）
- 分隔线：1px `divider`
- 按下态：整行 `fillSubtle`
- 角标：`SQ` 用 primary 描边小胶囊；源标记（`tx`/`kw`）用 muted 文字

## 5. 迷你播放条

三段式：
1. 左：方形封面 48×48（圆角 8）+ 两行文字（标题 / 歌手，muted）
2. 中：当前时间 + 进度条（已播 primary，未播 `#EEEEEE`）+ 总时长
3. 右：一排图标（收藏 / 歌词 / 音量 / 循环 / 上一首 / 播放暂停 / 下一首）
- 手机版：左右两段压缩，中间进度条保留但缩短；控件保留「收藏 / 播放暂停 / 下一首」三个
- 背景：玻璃态（`expo-blur`），圆角 14，距 TabBar 8

## 6. 与当前实现的差异清单

| 项 | 现状 | 目标 |
|---|---|---|
| 页签数量/文案 | 音乐/我的列表/歌单/榜单/搜索 | 搜索/歌单/排行榜/我的列表/下载/设置 |
| 设置入口 | 模态 settingModal | 独立页签 + 14 分区列表 |
| 下载页 | 不存在 | 新增骨架（筛选胶囊 + 任务列表 + 空态） |
| 歌单卡 | 上图下文 2 列网格 | 左图右文，标题 2 行 + 曲目数/播放量 |
| 歌曲行 | 仅标题/歌手 | 五列（序号/歌名/艺术家/专辑/时长） |
| 主色 | 当前主题色 | `#E240F7` |
| 播放条 | 简单横条 | 三段式 + 玻璃态 |
| 排行榜 | 单列卡片列表 | 源胶囊 + 榜单胶囊 + 五列歌曲行 |

## 7. 验收口径

1. 六页签文案/顺序/选中色与本文一致
2. 每页截图与 `references/mac-ui/screenshots/mac-<page>.png` 逐一对照，结构一致（不要求像素级）
3. 五列歌曲行在歌单详情、榜单详情、搜索结果三处复用同一组件
4. 深链 8 条全部可用
